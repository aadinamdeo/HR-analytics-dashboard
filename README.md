# 📊 HR Analytics Dashboard (Power BI)

## 🔍 Overview
This project analyzes employee attrition and workforce trends using Power BI.

## 📌 Key Metrics
- Total Employees: 1413
- Attrition Count: 229
- Attrition Rate: 16.21%
- Average Age: 37
- Average Salary: 6.5K

## 📊 Key Insights
- Highest attrition observed in **26–35 age group**
- Majority attrition in **salary < 5K**
- Roles like **Laboratory Technician & Sales Executive** show high attrition

## 🛠️ Tools Used
- Power BI
- DAX
- Data Modeling
